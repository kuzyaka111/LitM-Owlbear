# Проверка версии 0.1.0

- npm test: 11 проверок пройдены. Проверены фильтр GM, запрет открытия игроком, жизненный цикл роли/сцены, адреса под подпапкой, локальное сохранение и изоляция по пользователю/комнате, ввод текста и действия интерфейса.
- npm run build: успешно.
- Собранные страницы проверены в Chromium через Playwright: загрузка ресурсов, выбор тегов, сохранение имени после перезагрузки, добавление тегов сцены.
- Проверена ширина листа 1000, 736, 375 и 320 px; панели ведущего — 620, 375 и 320 px. Горизонтального выхода за окно не обнаружено. Ошибок выполнения JavaScript не обнаружено.
- Скриншоты листа на компьютере и телефоне и панели ведущего просмотрены.

## Ещё не проверено

Установка по публичной ссылке и работа в настоящей комнате Owlbear с двумя участниками. Проверки интеграции используют имитацию SDK; они не заменяют проверку в Owlbear. Общей базы и синхронизации данных пока нет.

## Исправление manifest 0.1.1

После сообщения о 404 внутри листа проверены опубликованные index.html, gm.html и background.html: HTTP 200. В manifest относительные пути заменены полными адресами с /LitM-Owlbear/, чтобы разрешение относительно корня домена не теряло подпапку проекта. Регрессионная проверка покрывает оба базовых адреса и совпадение исходного и опубликованного manifest. Подтверждение результата в комнате Owlbear ещё требуется.
