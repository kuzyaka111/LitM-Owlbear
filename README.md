# Легенда в Тумане — расширение Owlbear Rodeo

Версия 0.5.2. Редактируемые карточки персонажа, тем, братства и рюкзака.

## Интерфейс

- Кнопка «Лист персонажа» в расширениях открывает компактный прозрачный Popover ниже верхней панели (отступ 96 px). Туман находится под карточками. Размер окна зависит от вкладки и размера экрана.
- «Персонаж и Братство»: сначала общее братство, затем персонаж, рюкзак и дополнительные карточки. Основной Рюкзак постоянный: без главного тега, отдельной строки названия и удаления. «+ Хранилище» создаёт дополнительные удаляемые карточки с редактируемым двойным нажатием названием. Также можно добавлять сюжетные темы. Возврата удалённых или прежних карточек нет.
- «Темы»: четыре основные темы. «Заметки»: первой карточкой расположен компендиум всех заметок. Нажатие на запись открывает её справа; повторное нажатие переходит к уже открытой карточке. «+ Заметка» находится в компендиуме.
- Крестик открытой карточки только закрывает её. Крестик в компендиуме спрашивает подтверждение и удаляет заметку целиком. Состояние открытых карточек сохраняется.
- Внутри заметки есть сворачиваемые заголовки и вложенные подзаголовки, каждый со своим текстом. Сама карточка не сворачивается. Старые разделы переносятся в заголовки с сохранением названий и текста.
- Развёрнутые основные карточки имеют размер 224 × 560 px. Панель выбранных тегов — исключение: её высота зависит от содержимого. Ряд прокручивается только при нехватке ширины. Раскрытые улучшения и длинные записи могут прокручиваться внутри карточки.
- Справа — отдельная тёмная карточка тегов действия с разделами силы и слабости. Она скрыта при пустом выборе, и окно не резервирует для неё место. Можно выбирать теги из карточек или вводить временные теги.
- В любой теме, включая братство и дополнительные темы, можно независимо выбрать Истоки, Приключение или Величие. Темник не ограничивает выбор. При смене темника с сохранением записей сохраняется и Могущество.
- У темы фиксировано семь тегов силы (название + шесть) и три тега слабости. Двойное нажатие превращает тег/стремление в поле ввода прямо на карточке. Нажатие вне поля сохраняет изменение; значок из трёх диагональных следов когтей зачёркивает тег; повторное нажатие восстанавливает его.
- Ромб с буквой показывает вопрос при наведении; нажатие открывает полный список вопросов темника. У сюжетных тем нет выбора темника и книжных вопросов.
- Есть счётчики развития, отказа и вех. В раскрываемых разделах заранее перечислены особые улучшения темника и квинтэссенции. Пустой ромб означает неактивное улучшение, заполненный — активное; нажатие переключает состояние. Неактивный текст оформлен как «Пустой тег». Нажатие на название книжного улучшения показывает описание. Последствия правил автоматически не рассчитываются.
- Панель ведущего доступна отдельной кнопкой в инструментах только GM при открытой сцене. Проверка роли выполняется также при открытии страницы; смена роли скрывает панель.

Дополнительные темы во вкладке «Персонаж и Братство» имеют закреплённый тип «Сюжетная тема». Выбор Могущества сохраняется. Их улучшения — пять заполняемых строк с ромбами активности, редактируемых двойным нажатием. Ранее созданные дополнительные темы преобразуются с сохранением тегов, заметок и выбранных улучшений.

## Каталог

`src/themebooks.json` содержит 20 основных темников и Братство: 10 вопросов силы и 4 слабости на каждый, 105 особых улучшений и 18 квинтэссенций. Темники переменной мощи: Companion (Спутник), Magic (Магия), Possessions (Владения); Fellowship также поддерживает все три уровня.

Источник — предоставленный пользователем *Legend in the Mist, Volume I: The Hero* (2025), страницы 92–131, 140–141, 194–195. Вопросы, названия и описания улучшений оставлены на английском из оригинала; русские названия темников — рабочие обозначения интерфейса, не официальный перевод. Сведения об источнике и страницы включены в каталог.

## Хранение

Личный лист, основные и дополнительные темы, рюкзак и заметки хранятся в localStorage отдельно для каждой комнаты и игрока на этом устройстве. Supabase пока не подключён. Братство сохраняется по отдельным полям в метаданных комнаты Owlbear и обновляется у участников, независимо от сцены. Одновременная запись одного и того же поля использует последнее обновление.

Старый ключ localStorage сохранён. Перед первой записью версии 4 создаётся резервная копия прежнего значения с суффиксом `:before-v4`. Старые заметки и квинтэссенции сохраняются; теги дополнительных тем сверх шести переходят в отдельный рюкзак. Ошибки сохранения отображаются в интерфейсе; при ошибке общего сохранения поле остаётся редактируемым с черновиком. Изменения других участников не заменяют незавершённый ввод.

## Разработка и проверка

Node.js 24, `npm ci`, `npm test`, `npm run dev`. Сборка: `npm run build`. Содержимое `dist/` копируется в `docs/`; старые хешированные ресурсы оставляются для кэшированных страниц. Секретные ключи для этой версии не нужны.

Подробности проверки — `VALIDATION.md`. Поведение окна над настоящей картой и синхронизацию двух реальных участников следует проверить в Owlbear; проверки с имитацией SDK не заменяют эту проверку.

Иконки Lucide: ISC, см. `THIRD_PARTY_NOTICES.txt`. Это неофициальное расширение.

При каждом открытии листа HTML запрашивается с новым параметром адреса, чтобы не переиспользовать устаревшую страницу из десятиминутного кэша GitHub Pages. Текущая версия видна в разделе «Сохранение» карточки персонажа.

В тексте заметки строка, начинающаяся с `- `, продолжает список по Enter с тем же отступом. Enter на пустом пункте убирает маркер и завершает список. Shift+Enter вставляет обычный перевод строки. Это текстовый формат с маркерами; HTML из заметок не выполняется.

Редактируемое поле сохраняет размеры, отступы и шрифт исходного текста, в том числе имени спутника. Вместо рамок и обводок используется светлый полупрозрачный фон. Ромбы счётчиков внутри троек расположены на 20% ближе (шаг 18,4 вместо 23 px), пространство между группами увеличено. Если основной Рюкзак был удалён в прежней версии, возвращается пустой постоянный Рюкзак; содержимое остальных карточек сохраняется.
