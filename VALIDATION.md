# Проверка версии 0.1.0

- npm test: 11 проверок пройдены. Проверены фильтр GM, запрет открытия игроком, жизненный цикл роли/сцены, адреса под подпапкой, локальное сохранение и изоляция по пользователю/комнате, ввод текста и действия интерфейса.
- npm run build: успешно.
- Собранные страницы проверены в Chromium через Playwright: загрузка ресурсов, выбор тегов, сохранение имени после перезагрузки, добавление тегов сцены.
- Проверена ширина листа 1000, 736, 375 и 320 px; панели ведущего — 620, 375 и 320 px. Горизонтального выхода за окно не обнаружено. Ошибок выполнения JavaScript не обнаружено.
- Скриншоты листа на компьютере и телефоне и панели ведущего просмотрены.

## Ещё не проверено
