# Проверка версии 0.2.0

- `npm test`: 21 проверка пройдена. Роли и окна GM, пути GitHub Pages, сохранение личного листа и экранирование ввода.
- Миграция v0.1: сохраняются имя, полный текст заметок, отметки и предметы; пустой рюкзак и пустые заметки остаются пустыми. Старые предметы переходят в первую карточку рюкзака.
- Карточки: оба типа, редактирование, добавление/удаление тегов, удаление карточки и отмена удаления, сохранение после повторного открытия. Одинаковые названия тегов на разных карточках имеют независимый выбор.
- Братство: два клиента с имитацией Room API видят изменения друг друга; частичные записи сохраняют чужие поля и данные других расширений. Проверены гонка начальной загрузки, ограничение размера метаданных, отказ записи и сохранение незавершённого ввода при чужом обновлении.
- `npm run build`: успешно.
- Собранные страницы проверены в Chromium через Playwright: четыре вкладки, миграция старых заметок и предметов, добавление обоих типов карточек, удаление и отмена, заполнение братства в локальном предпросмотре, расход/восстановление тегов, сохранение после перезагрузки.
- Все четыре вкладки проверены на ширинах 1000, 736, 375 и 320 px. Панель ведущего — 620, 375 и 320 px. Горизонтального выхода за окно и ошибок JavaScript нет. Скриншоты просмотрены; длинные названия карточек и имя героя переносятся на строки.

## Проверка в настоящем Owlbear

Пользователь подтвердил открытие листа и окна ведущего в версии 0.1.1. Для 0.2.0 ещё требуется проверка синхронизации братства с двух настоящих участников комнаты, в том числе без открытой сцены. Модульные тесты с имитацией SDK этого не заменяют.

Существующие личные заметки не отправляются в комнату. Supabase не подключён. Персонаж, инвентарь и заметки остаются локальными; общее братство хранится в метаданных комнаты Owlbear.

## Публикация

Полные адреса страниц в manifest сохраняют подпапку /LitM-Owlbear/. Предыдущие хешированные ресурсы в docs/assets оставлены, чтобы кэшированная старая страница продолжала загружаться во время обновления.
